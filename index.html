FAQ

Everything you need to know.

Does Eclipse work on older PCs?

Yes. The client is built to reduce stutter, lower RAM usage, and improve frame stability on lower-end systems.

Is it easy to customize?

Absolutely. The HUD is drag-and-drop and modules can be enabled or disabled in seconds without a complex setup flow.

Does it support multiple Minecraft versions?

Yes. Eclipse supports 1.8.9, 1.20.1, 1.21.11, 26.2, and 26.3 to fit different game setups.

Does it detect the operating system automatically?

Yes. The download text updates automatically so it can show Windows, Linux, or Mac correctly for your system.
